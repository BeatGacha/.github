## API Documentation
If you want to work with the API, please read [the documentation](https://beatgacha.com/api-docs) on how to do so.  
By using the API, you automatically accept the terms outlined [here](https://beatgacha.com/terms).  

To avoid abuse, OAuth apps are manually created by the BeatGacha-team.
